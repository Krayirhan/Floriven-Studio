# 19 — Definition of Done

Bir feature DONE değildir sadece:
- typecheck geçti,
- unit geçti,
- UI ekranda bir şey gösterdi

diye.

## Component DoD

- typed contract
- resolver mapping
- renderer
- states
- a11y
- narrow viewport
- visual fixture
- unit test
- regression snapshot

## Composer DoD

- archetype contract
- semantic mapping
- preset modifier
- deterministic fixture
- structural test
- screenshot test
- geometry pass

## Preset DoD

- all required profile fields resolved
- no preset-id branch in renderer
- six archetypes pass
- pairwise structural distance
- grayscale distinguishability
- chart families correct
- typography correct
- navigation correct

## Sprint DoD

- acceptance criteria pass
- no unresolved P0/P1
- docs updated
- migration considered
- visual snapshots reviewed
- instrumentation included

## Release DoD

- typecheck
- lint
- unit
- integration
- E2E
- visual regression
- accessibility
- performance
- security
- certification
- rollback rehearsal
