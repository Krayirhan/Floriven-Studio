# 10 — Five Presets — Runtime Completion Spec

## Genel preset acceptance

Bir preset yalnızca aşağıdakiler değişiyorsa tamamlanmış değildir:

- color
- radius
- shadow

Tamamlanmış preset aşağıdakilerde ölçülebilir fark üretir:

- composition
- geometry
- typography hierarchy
- card family
- chart family
- control treatment
- grouping
- navigation
- density
- motion

## Obsidian Precision

Must:
- compact strict-grid / bento
- glass surfaces
- tabular metrics
- geometric icons
- rich operational charts
- controlled cyan accent

Must not:
- generic dark SaaS stack
- oversized rounded cards
- sparse wellness spacing

## Serene Flow

Must:
- stacked calm hierarchy
- soft surfaces
- spacious touch targets
- area/radial data
- semantic status language

Must not:
- merely green + 24px radius
- dense technical grid

## Terracotta Atelier

Must:
- editorial asymmetry
- paper/layered surfaces
- serif display hierarchy
- editorial media treatment
- warm bar/segmented charts

Must not:
- generic commerce UI + serif font

## Electric Pulse

Must:
- bento / playful grouping
- progress/reward hierarchy
- radial/donut data
- energetic controls
- high contrast

Must not:
- purple gradient + generic line chart

## Editorial Grid

Must:
- typographic hierarchy
- divider-led grouping
- asymmetric layout
- flat surfaces
- sparse mini charts
- strong whitespace

Must not:
- serif + underline fields only
- vertical receipt layout

## Cross-preset test

Color information kaldırıldığında pairwise structural distance:

```text
>= 0.40
```

olmalıdır.
