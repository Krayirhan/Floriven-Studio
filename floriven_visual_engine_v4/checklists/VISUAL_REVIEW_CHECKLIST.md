# Visual Review Checklist

## Hierarchy
- [ ] İlk bakışta primary information anlaşılır
- [ ] Primary CTA doğru ağırlıkta
- [ ] Secondary content primary ile yarışmıyor

## Layout
- [ ] Archetype açıkça belli
- [ ] Gereksiz card stack yok
- [ ] Alignment kasıtlı
- [ ] Whitespace kontrollü

## Typography
- [ ] Minimum font okunabilir
- [ ] Heading scale coherent
- [ ] Numeric data uygun biçimde vurgulu

## Components
- [ ] Input'lar gerçek affordance taşıyor
- [ ] Status görünür
- [ ] Controls touch-safe
- [ ] Chart gerçekten bilgi taşıyor

## Preset
- [ ] Renkleri kaldırınca karakter hâlâ var
- [ ] Preset contract'a uyuyor
- [ ] Başka presetin component grammar'ına kaymıyor
