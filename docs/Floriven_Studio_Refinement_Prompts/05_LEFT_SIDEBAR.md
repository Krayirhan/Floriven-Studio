# 05. Left Sidebar

## Amaç

Floriven Studio ana çalışma alanında yalnızca **Left Sidebar** birimini iyileştirmek. Diğer başarılı bölümleri korumak.

## Kullanım

Mevcut Floriven Studio ekran görüntüsünü referans olarak yükleyin ve aşağıdaki promptu tek başına uygulayın.
