# Golden screen registry

Golden screens are semantic reference fixtures, not pixel copies. Each fixture
must preserve its intended tree shape, pattern choices, information density,
action placement, and surface strategy.

- `golden-settings`
- `golden-dense-list`
- `golden-form`
- `golden-detail`
- `golden-dashboard`
- `golden-analytics`

A final generation is eligible only when schema, accessibility, structural,
geometry, semantic, visual, and cross-screen gates all pass.
